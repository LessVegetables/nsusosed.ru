# nsusosed.ru

Соседи по комнате из НГУ, которые живут в твоём ритме.

Закрытый сайт для студентов НГУ. Ты отвечаешь на короткую анкету о бытовых привычках, а сайт показывает комнаты в общежитии и квартиры со свободными местами, отсортированные по тому, насколько твои привычки совпадают с привычками тех, кто там уже живёт.

[English version](readme.md)

## Проблема

- **Общежитие.** При заселении комендант называет свободные комнаты по номерам («есть 122, 512, 412 и 302, куда хочешь?»). Студент выбирает, не зная, кто там живёт, и узнаёт, как живут соседи, только после въезда.
- **Съёмная квартира.** Если соседи съехали, оставшийся платит за пустые комнаты. Чаты, листовки, ЦИАН и Авито не помогают найти студента своего вуза.

## Для кого

1. **Первокурсники, которые заселяются в общежитие.** Выбирают комнату по тем, кто в ней уже живёт.
2. **Жильцы комнаты, где освободилось место.** Хотят, чтобы въехал человек с похожим режимом.
3. **Студенты, которые снимают квартиру со свободной комнатой.** Хотят найти соседа-студента НГУ.

## Как это работает

1. **Регистрация и вход** по почте `@g.nsu.ru`. Паролей нет: каждый раз на почту приходит одноразовый код, который действует 2 минуты. При регистрации ты также соглашаешься с политикой обработки персональных данных.
2. **Знакомство с сайтом**, по одному шагу на экран. Сначала выбираешь язык интерфейса (его можно сменить в «Аккаунте») и что ищешь: **жильё** или **соседа в своё жильё**. От этого ответа зависит всё остальное.
3. **Анкета** (10 вопросов). По каждой привычке указываешь:
   - свой ответ;
   - насколько это важно (1–10);
   - при желании **принципиальное условие**: какие ответы соседа для тебя неприемлемы (например, «в комнате не курят»).

   Кто ищет жильё, указывает месячный бюджет (нужен для квартир). Кто ищет соседа, описывает жильё: комнату или квартиру, сколько угодно контактов, фото и живут ли там уже соседи (если да — получает ссылку-приглашение для них).
4. **У жилья есть админы, а не автор.** Кто добавил жильё, тот его админ. Админы правят карточку, приглашают соседей и могут сделать админом любого жильца, заполнившего анкету. Если уходит последний админ, админом становится тот, кто дольше всех живёт там на сайте; если уходит последний жилец, жильё удаляется. Жить можно только в одном жилье, и кто живёт в жилье, тот его не ищет. Админ подтверждает карточку раз в 30 дней, иначе она скрывается.
5. **Подбор.** Ищущим показывается жильё со свободными местами, отсортированное по проценту совместимости, с коротким объяснением («режим сна совпал, по уборке расхождение»). «Показать неподходящие» добавляет то, что не проходит по принципиальным условиям или бюджету, с объяснением почему.
6. **Контакты жильцов.** В карточке все контакты, которые указали жильцы: Telegram, WhatsApp, Max, телефоны и что угодно ещё. О заселении договариваются вне сайта.

## Три core-функции

| # | Функция | Готово, когда |
|---|---|---|
| F1 | **Анкета.** Вход без пароля по коду на почту; знакомство с сайтом в зависимости от роли; анкета из 10 вопросов, которую можно изменить | Пользователь может войти по коду, сохранить ответы и изменить их |
| F2 | **Карточка жилья.** Общежитие: корпус, комната, этаж, вместимость, занятые места, угловая или нет, окна, вид, планировка. Квартира: район, стоимость в месяц на человека. Плюс описание, фото и любое число контактов. Жильцы присоединяются по ссылке-приглашению, жильём управляют админы | Жильё создано, жильцы и админы к нему привязаны |
| F3 | **Подбор и контакт.** Отфильтрованный и отсортированный список с объяснением оценки, по желанию — вместе с неподходящим; контакты показаны в карточке | Пользователь видит подходящее ему жильё и может связаться с жильцами |

Также входит в MVP: вход и выход, редактирование и пауза карточки, удаление аккаунта, интерфейс на русском и английском, вёрстка для телефона и компьютера.

## Правила подбора

- **Вопросы:** время отхода ко сну, время подъёма, шум ночью, уборка, гости, курение в комнате, алкоголь в комнате, учёба в комнате, проветривание, температура.
- **Сначала фильтр по принципиальным условиям, в обе стороны.** Если хотя бы один жилец нарушает твоё условие, или ты нарушаешь его, жильё скрыто, каким бы высоким ни был средний процент. «Показать неподходящие» всё равно его покажет — после подходящего и с причиной.
- **Квартиры:** скрыты (или, с этой галочкой, помечены), если цена на человека выше твоего бюджета.
- **Анкеты старой версии** продолжают работать: вопрос, на который одна из сторон ещё не ответила, в оценке не участвует.
- **Профиль комнаты:** среднее по жильцам, которые заполнили анкету. Если заполнили не все, в карточке пишется «Ответили 2 из 3 жильцов».
- **Оценка (0–100%):** сходство ответов по каждому вопросу с весом по важности для обеих сторон. Это индекс сходства, а не гарантия отсутствия конфликтов.
- Не показываются комнаты без свободных мест, без заполненных анкет жильцов, а также карточки старше 30 дней.

## Не входит в MVP

- Поиск компании для аренды, пока квартиры ещё нет (размещаются только существующие квартиры со свободными комнатами)
- Встроенный чат, бронирование, официальное распределение мест (решение по-прежнему за комендантом)
- Оплата, в том числе платные объявления о квартирах
- Другие вузы кроме НГУ; мобильные приложения

## Стек

FastAPI + PostgreSQL, чистый HTML/CSS/JS без фреймворков, Nginx, один VPS в Selectel. Письма с кодом отправляются через Yandex Cloud Postbox. ИИ-модели не используются, оценка считается простой формулой.
